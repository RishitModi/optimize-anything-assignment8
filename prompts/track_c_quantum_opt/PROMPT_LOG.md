3.1 qsim.py: a numpy statevector simulator.
Convention (document at the top): n qubits, state is a complex128 vector of length 2^n; basis index i has bits x_0 x_1 ... x_{n-1} with qubit 0 the MOST significant bit, x_k = (i >> (n-1-k)) & 1. Bit 0 corresponds to |0> and Z eigenvalue +1, so Ising spin s_k = 1 - 2 x_k.
Provide: zero_state(n), plus_state(n); gate matrices I, X, Y, Z, H and ry(theta), rx(theta), rz(theta) with RY(theta) = exp(-i theta Y / 2), RX(theta) = exp(-i theta X / 2); apply_1q(state, U, q, n) (reshape to (2**q, 2, 2**(n-q-1)) and contract with U); apply_cnot(state, control, target, n) (reshape to (2,)*n, select the control=1 slice, flip the target axis, assign back on a copy); apply_pauli_string(state, "XZIY"); expectation_diag(state, diag) = sum |psi|^2 diag; expectation_pauli_hamiltonian(state, terms) where terms is a list of (coef, pauli_string); sample_counts(state, shots, rng) via rng.multinomial on |psi|^2; estimate_energy_shots(state, terms, shots, rng): Hamiltonians contain only Z/I strings and X/I strings (raise ValueError otherwise); the Z group is measured by sampling in the computational basis and taking the parity over the string's Z positions; the X group is measured after applying H to all qubits, then the same parity rule; each group gets `shots` shots; returns the weighted sum of the term estimates. apply_depolarizing_layer(state, p, rng, n): for each qubit independently, with probability p apply a uniformly random Pauli from {X, Y, Z} (one noise trajectory). dense_matrix_from_terms(terms, n) via Kronecker products with the same bit ordering, for n <= 10.

3.2 qaoa.py
- load_instances(path="results/track_b/qubo_instances.json"): returns a list of dicts with n, Q (np.array), h, J (dict with "i,j" keys converted to tuples), offset, opt_energy, opt_cut, opt_bitstrings.
- qubo_diag(Q): energies x^T Q x of all 2^n basis states, with the bit convention above (build the bit matrix from the index).
- ising_diag(h, J, offset, n): energies with s = 1 - 2x.
- qaoa_state(params, diag, n, p, noise_p=0.0, rng=None): params = [gamma_1..gamma_p, beta_1..beta_p]; start from |+>^n; for each layer multiply amplitudes by exp(-i gamma diag), then apply RX(2*beta) = exp(-i beta X) to every qubit; if noise_p > 0 apply apply_depolarizing_layer after the cost layer and after the mixer layer.
- qaoa_expectation(params, diag, n, p); qaoa_expectation_shots(params, diag, n, p, shots, rng) via sampling bitstrings and averaging diag over samples.
- approximation_ratio(expected_energy, opt_energy) = expected_energy / opt_energy (both energies are negative cuts, so this equals expected cut / optimal cut); prob_optimal(state, opt_bitstrings, n).
- run_qaoa(instance, p, n_inits, seed, maxiter): for each initialisation (gamma ~ U[0, pi], beta ~ U[0, pi/2]) minimise qaoa_expectation with scipy.optimize.minimize(method="COBYLA", options={"maxiter": maxiter}), counting every objective call with a counter wrapper; return per-init results (final expectation, ratio, prob_optimal, n_evals) and the best parameters.

3.3 vqe.py
- tfim_terms(n, g): open chain H = -sum_{i=0}^{n-2} Z_i Z_{i+1} - g sum_i X_i as a list of (coef, pauli_string).
- exact_ground_energy(terms, n) via numpy.linalg.eigvalsh of dense_matrix_from_terms.
- Ansatz (hardware efficient, real): L layers; each layer = RY(theta) on every qubit followed by a CNOT chain (0->1, 1->2, ..., n-2 -> n-1); then one final RY layer; parameter count P = n*(L+1); parameters are ordered layer by layer, qubit by qubit.
- ansatz_state(params, n, L, noise_p=0.0, rng=None) (noise applied after every RY layer and after every CNOT chain).
- vqe_energy(params, terms, n, L).
- param_shift_grad(params, terms, n, L): for RY, dE/dtheta_i = 0.5 * (E(theta_i + pi/2) - E(theta_i - pi/2)); cost 2P evaluations.
- metric_tensor(params, n, L): exact Fubini-Study metric. For parameter i let phi_i be the state obtained by running the circuit and applying the Pauli Y on the gate's qubit immediately after RY gate i (then continuing with the remaining gates); then g_ij = 0.25 * ( Re<phi_i|phi_j> - Re( <phi_i|psi> <psi|phi_j> ) ), psi being the ansatz state. Document that this uses derivative states that are not directly measurable on hardware.
- A function that builds all phi_i efficiently (P+1 circuit runs).

3.4 optimizers_q.py: each optimizer takes a callable energy(params) and returns a history list of (cumulative_circuit_evaluations, exact_energy_at_current_params) recorded after every iteration, where the exact energy used for monitoring is NOT counted as an evaluation.
- gd_param_shift(params0, grad_fn, lr, n_steps, cost_per_step)
- spsa(params0, loss_fn, a, c, n_steps, seed, A=None): standard gains a_k = a / (k + 1 + A)^0.602, c_k = c / (k + 1)^0.101, A = 0.1 * n_steps, Rademacher perturbation, g_hat = (f(theta + c_k d) - f(theta - c_k d)) / (2 c_k) * (1/d); 2 evaluations per step independent of P.
- qng(params0, grad_fn, metric_fn, lr, n_steps, reg=1e-3, cost_per_step): theta <- theta - lr * solve(g + reg*I, grad).
- cobyla(params0, loss_fn, maxiter) via scipy COBYLA, counting evaluations and recording energy history through the callback and the evaluation counter.
