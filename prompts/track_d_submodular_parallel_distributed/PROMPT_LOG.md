2.1 submodular.py
- make_coverage_instance(n_elements=300, n_sets=40, seed): each set contains a random subset (size 10 to 40) of the universe.
- coverage(selected_sets, sets) = size of the union. greedy(f_marginal-based) with a function-evaluation counter; lazy_greedy using a max-heap of stale upper bounds (same result as greedy, fewer evaluations; count evaluations).
- exact_max_coverage(sets, n_elements, k) with scipy.optimize.milp: binary x_j per set, binary y_e per element, y_e <= sum_{j containing e} x_j, sum x_j <= k, maximise sum y_e.
- check_submodularity(f, ground_set, n_trials, seed): sample random A subset of B and e not in B, test f(A+e) - f(A) >= f(B+e) - f(B) - 1e-9; return the number of violations and the worst violation.
- r2_objective(X, y): returns f(S) = R^2 of ordinary least squares with intercept on the feature subset S (f(empty) = 0), implemented with numpy lstsq on standardised data.
- Instance for the non-submodular case: sklearn make_regression(n_samples=300, n_features=15, n_informative=6, effective_rank=8, noise=5, random_state=0) with a few columns made near-duplicates or linear combinations of others so that suppressor-style interactions appear (add column 14 = col 0 + col 1 + small noise and replace column 13 by col 2 - col 3 + small noise).

2.2 parallel_tools.py (worker module). At the very top, BEFORE importing numpy, set os.environ for OMP_NUM_THREADS, MKL_NUM_THREADS, OPENBLAS_NUM_THREADS to "1" so workers do not oversubscribe cores. Provide:
- burn(n_iter): pure-Python CPU-bound loop (an integer LCG update repeated n_iter times); calibrate_iters_per_ms() measured over about 0.3 s.
- run_task(n_iter) used by the pool; run_chunk(list_of_n_iter).
- simulate_static_block(durations, p), simulate_static_round_robin(durations, p), simulate_list_scheduling(durations, p) (each next task goes to the worker that becomes free first, in given order), simulate_lpt(durations, p) (list scheduling after sorting by decreasing duration), simulate_work_stealing(durations, p, steal_cost, seed): tasks are first dealt in contiguous blocks to p deques; an idle worker steals half of the remaining tasks (at least one) from the back of the deque of the worker with most remaining work, paying steal_cost time; discrete-event simulation; each returns the makespan. lower_bound(durations, p) = max(sum/p, max duration).
- pipeline_makespan(n_stages, n_micro, stage_times): standard pipeline (GPipe-style forward only) schedule: makespan from the recurrence finish[m][s] = max(finish[m][s-1], finish[m-1][s]) + stage_times[s]; also return the bubble fraction 1 - (sum of work)/(n_stages * makespan).
- data-parallel workers: grad_shard_resident(args) where each worker generates its own shard of a logistic-regression problem from (seed, shard_index, n_per_shard, d) once per call (no data shipped) and returns the gradient of the logistic loss at w (w is sent each call); grad_shard_shipped(args) which receives the shard arrays X, y and w as arguments (data shipped on every call).
