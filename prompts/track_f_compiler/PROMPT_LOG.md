2. cc_ir.py: basic blocks and CFG construction from a linear IR (block leaders: first instruction, labels, instruction after a jump), reverse conversion back to a linear list; liveness analysis by iterative backward dataflow over the CFG giving live-in and live-out sets per block and a function live_at_each_instruction(ir) returning the set of variables live immediately before every instruction; loop_depth_per_instruction(ir): for every backward jump (jmp to a label that appears earlier) the instructions between that label and the jump are inside one loop, and the depth of an instruction is the number of such ranges containing it; an IR interpreter run_ir(ir, step_limit=2_000_000) returning (output list, dynamic instruction count excluding labels, wall time) and raising on step limit; pure(op) helper: ops other than print/jmp/jz/label/halt are pure EXCEPT div and mod, which are only treated as removable when the divisor is a non-zero integer constant.

3. cc_passes.py: optimisation passes, each a function ir -> new ir (never mutating the input), plus pass registry and optimize(ir, passes, max_iters=10) which applies the list repeatedly until nothing changes, and records for each pass the time spent.
 (a) const_fold_prop: within each basic block propagate constants and copies (mov x, 5; mov x, y) into later operands until the variable is redefined, fold operations whose operands are constants using eval_op (never fold div or mod with a zero divisor), turn "jz const L" into jmp or a deletion (branch folding).
 (b) algebraic_strength_reduction: x + 0, x - 0, x * 1, x / 1 -> mov; x * 0 -> mov 0; x * 2^k -> shl x, k; x / 2^k -> shr x, k (valid for floor division); x % 2^k -> and x, 2^k - 1 (valid for Python modulo); x - x -> 0; also constant on the left for commutative ops.
 (c) cse: local value numbering within a basic block: every variable maps to a value number that changes at each redefinition; an expression key is (op, vn(a), vn(b)) with operands of commutative ops (add, mul, and, eq, ne) in sorted order; if an earlier instruction in the same block computed the same key and the variable holding it still has that value number, replace the new computation by mov dst, that_variable; invalidate entries whose holder variable is redefined.
 (d) dce: remove (i) pure instructions whose destination is not live afterwards (use liveness over the CFG; div and mod only when the divisor is a non-zero constant), (ii) instructions that can never execute (after an unconditional jmp or halt up to the next label that is still referenced), (iii) jumps to the immediately following label and labels that are no longer referenced.

4. cc_regalloc.py: register allocation as a 0/1 optimisation problem.
 - build_live_ranges(ir): for every variable, its live range as the interval [first index where it is live or defined, last index where it is live or used], i.e. the convex hull over the linear instruction order, built from live_at_each_instruction plus defs/uses; weight w_i = sum over every definition and use of the variable of 10 ** loop_depth(instruction).
 - Formulation (document in the docstring): variables x_i in {0,1} (live range i is kept in a register), maximise sum_i w_i x_i subject to, for every instruction index t, sum over ranges containing t of x_i <= k; spill cost = sum_i w_i (1 - x_i). Note in a comment that the constraint matrix has the consecutive-ones property, so the LP relaxation is integral.
 - allocate_linear_scan(ranges, k) (Poletto and Sarkar: process by start; when more than k are active spill the active range with the furthest end, which may be the new one), allocate_greedy_weight(ranges, k) (sort by weight descending, keep a range if adding it keeps every point at most k), allocate_ilp(ranges, k) with scipy.optimize.milp (integrality=1, bounds 0..1; use a sparse or dense constraint matrix with one row per distinct overlap point set; deduplicate identical rows), allocate_bruteforce(ranges, k) for at most 18 ranges. Every function returns (kept set, spilled set, spill_cost, solve_time). Assign physical registers to kept ranges by interval colouring (sweep by start, reuse a free register), and give each spilled variable a memory slot.
