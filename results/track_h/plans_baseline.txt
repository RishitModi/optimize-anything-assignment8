Query: Q4 (Orders Lineitem Join 6-day Window)
SQL: SELECT COUNT(*), SUM(o.o_totalprice) FROM orders o JOIN lineitem l ON l.l_orderkey = o.o_orderkey WHERE o.o_orderdate BETWEEN ? AND ?
----------------------------------------
EXPLAIN QUERY PLAN:
SCAN l
BLOOM FILTER ON o (o_orderkey=?)
SEARCH o USING AUTOMATIC PARTIAL COVERING INDEX (o_orderkey=?)

Query: Q12 (Three-Way Join Aggregated by Nation)
SQL: SELECT n.n_name, COUNT(*) FROM customer c JOIN orders o ON o.o_custkey = c.c_custkey JOIN nation n ON n.n_nationkey = c.c_nationkey WHERE o.o_orderdate BETWEEN ? AND ? GROUP BY n.n_name ORDER BY n.n_name
----------------------------------------
EXPLAIN QUERY PLAN:
SCAN n
BLOOM FILTER ON c (c_nationkey=?)
SEARCH c USING AUTOMATIC COVERING INDEX (c_nationkey=?)
BLOOM FILTER ON o (o_custkey=?)
SEARCH o USING AUTOMATIC PARTIAL COVERING INDEX (o_custkey=?)
USE TEMP B-TREE FOR GROUP BY
